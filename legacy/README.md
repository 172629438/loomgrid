# 历史版本

这里是融合版（Pro）从 v1.1 到 v2.2 的完整演进史，共 8 个版本。主线 Ultra 走的是另一条路线，不在这个目录里。

**仅供考古与对比，不建议用于正式方案**。配置格式与现役版本不兼容，且早期版本存在已知缺陷（见下表）。

## 演进脉络

```
v1.1  读 Excel、画曲线、导出图片         —— 能用了
  ↓
v1.2  列映射、多资产                     —— 能处理真实数据了
  ↓
v1.3  配置持久化、策略组                 —— 不用每次重填
  ↓
v1.4  曲线融合、脱敏                     —— 开了新场景
  ↓
v2.0  专业分析窗口、储能测算雏形          —— 从"画图工具"变成"测算工具"
  ↓
v2.1  充放电空间、省份电价               —— 核心算法成型
  ↓
v2.2  双引擎架构（basic / professional） —— 开始分叉
  ↓
v2.3  独立重写，走精简路线               —— 与 Ultra 彻底分道
```

## 各版本的已知缺陷

### v1.1
- 无储能测算能力，纯负荷曲线工具
- 列识别只支持固定表头格式
- 中文文件名在部分系统上乱码

### v1.2
- 列映射只支持单文件，处理下一个文件要重新映射
- 无配置持久化

### v1.3
- 配置格式为早期版本，与后续不兼容
- 策略组只支持单省份

### v1.4
- 曲线融合功能是初版，仅支持两组曲线
- 脱敏算法固定，不可配置

### v2.0
- 专业分析窗口不稳定，部分标签页初始化顺序有问题
- 无充放电空间计算，只能手填容量

### v2.1
- 充放电空间的 SOC 口径未统一（不同位置用了 0% / 5% / 10% 三套）
- 电价时段只支持单一策略，无季节切换

### v2.2
- 双引擎架构的 professional 引擎有内存泄漏（长时间运行会吃满内存）
- 配置迁移有丢失风险，升级前需手动备份
- `v2.2` 目录里实际装的是 v3.0 的代码（历史命名错位）

### v2.3
- 流式处理，大批量吞吐只有 Ultra 三成
- 部分高级分析（MILP 精准规划、四目标优化）未实现
- 映射对话框的等待无超时，用户不操作会阻塞处理线程（此问题在仓库根目录的 v2.3 中已修复）

## 为什么保留这些版本

不是怀旧，是**回滚保险**。

当主线某个功能行为可疑时，可以拿旧版对照。判断逻辑很简单：

1. 用同一组数据跑旧版和现役版
2. 结果不同 → 要么是改坏了，要么是修正了错误
3. **看旧版的实现能不能解释这个差异**

2026-10 的一次全量审计就靠这个办法找回了 v3.0 的三层叠加引擎——它在 v3.2 里完全消失了，最后是从 `备份程序.py`（v2.29+ 快照）回填的。

## 使用注意

这些版本依赖的第三方库版本可能与现在不同。如果要跑，建议用虚拟环境：

```bash
python -m venv venv_legacy
venv_legacy\Scripts\activate
pip install PySide6 numpy pandas scipy matplotlib openpyxl
python LoomGrid-Fusion-v2.3.py
```

**不要用这些版本的文件去覆盖现役版本的配置目录**，配置格式不兼容会导致启动失败。
