# 负荷曲线批量生成工具 · Load Curve Studio

面向工商业储能方案设计的负荷曲线处理、容量测算与经济性评估工具链。桌面端单文件应用，PySide6 构建。

A desktop toolkit for commercial & industrial energy-storage pre-sales work: load-curve ingestion, BESS sizing, dispatch simulation and economics.

---

## 版本与文件关系

本仓库包含同一工具的两条技术路线与两个历史快照，**版本号与文件名并不同步**，按文件名判断版本会出错。

| 文件 | 内部版本 | 行数 | 定位 |
|---|---|---|---|
| `负荷曲线批量生成Ultra.py` | v3.2.0 | ~35.8k | **主线**。功能最全，含 MILP 精准引擎、25 行业参数库、诊断/报告/批量系统 |
| `负荷曲线批量生成工具 Pro 融合版 (v2.3).py` | 标称 v2.3，头部写 v3.2 | ~10.4k | 独立重写的精简版，吞吐量约为 Ultra 三成，不是裁剪而是另写 |
| `备份程序.py` | v2.29+ | ~32.2k | Ultra 的历史快照，保留 v3.0 三层叠加模拟引擎 |
| `参考程序.py` | v2.29 | ~31.8k | 更早的参考快照 |

### 关于文件名的历史遗留

- 目录名 `v1.4` 里装的是 v2.1，`v2.2` 目录里装的是 v3.0
- `备份程序.py` 比 `参考程序.py` 晚，多了 v2.30–v2.32 的部分补丁
- 融合版目录名写 `v2.3`，头部注释写 `智能增强版 v3.2`

## 主要能力

**数据接入**
- Excel/CSV 宽表批量读取，自动列类型识别（日期/时间/负荷/资产）
- 跨文件列映射复用，映射规则可导出
- 多资产长表与单表多月份两种形态

**负荷处理**
- 25 个行业参数库，支持参数化生成典型负荷曲线
- 三层叠加模拟引擎：省份 24h 基线 × 班制模板 × 设备 Markov 状态叠加 × 日间噪声平滑
- 光伏出力降粒度对齐，净负荷合成
- 指纹分析（连续生产 / 两班制 / 商业楼宇等）与行业自动匹配

**储能测算**
- 充放电空间计算（按容量 / 按需量两种基本电费模式）
- 三套调度引擎：贪心、日仿真、线性规划（LP）
- MILP 精准容量规划（OR-Tools CBC），支持多设备选型与更换周期建模
- 四目标 Pareto 优化：收益 / 回收期 / 循环寿命 / 需量削减
- 多场景容量扫描与方案对比

**经济性与诊断**
- NPV / IRR / LCOE / 动态回收期
- 月度电费结算对比
- 13 步综合诊断（数据质量、需量特征、负荷品质、容量推荐）
- 电池循环退化与更换成本建模

**交付输出**
- Matplotlib 批量出图，深浅双主题
- HTML 报告、方案建议书导出
- 技术偏差表与配置清单

## 运行要求

```
Python 3.10+
PySide6 >= 6.5
numpy / pandas / scipy
matplotlib
openpyxl
ortools        # MILP 容量规划（可选，缺失时自动降级）
```

启动：

```bash
python "负荷曲线批量生成Ultra.py"
```

按 `F1` 查看内置用户手册。

## 已知边界

- 单文件架构，Ultra 约 3.58 万行、96 个类。这是历史选择，拆分会改变所有相对引用，未做重构。
- `备份程序.py` / `参考程序.py` 中含若干**未实现的占位方法**（内部用常数估算，不是实测），例如月度结算里的 `×0.85`、快速测算里的 `容量 × 750`。这些方法在 Ultra 中未采纳，仅作为历史留存。
- 测算结果依赖输入数据的质量与列映射正确性，工具不校验外部数据的真实性。
